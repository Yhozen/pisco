neofetch 7.1.0, a bash script, runs on bash and busybox built as static Linux programs: 83 processes forked and
executed (fork, execve, wait4, pipes), each in a worker with memory of its own. A title image can now hold several
programs. In Chrome, fastfetch then neofetch, at real speed ([video](https://github.com/Yhozen/pisco/releases/tag/linux-fetch-video-2026-11-27)).
